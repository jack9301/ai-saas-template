通过无缝集成和自动部署，将您的 AI SaaS Template 应用程序部署到 Vercel。Vercel 为 Next.js 应用程序提供最佳的开发者体验，无需配置。

## 🚀 快速部署

### 一键部署

部署 AI SaaS Template 应用程序的最快方式：

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/AI SaaSr-saas)

### 手动部署

1. **安装 Vercel CLI**
   ```bash
   npm install -g vercel
   ```

2. **登录到 Vercel**
   ```bash
   vercel login
   ```

3. **从项目目录部署**
   ```bash
   vercel
   ```

4. **按照提示操作**
   - 设置并部署？ **是**
   - 选择哪个范围？ **选择您的账户**
   - 链接到现有项目？ **否**
   - 您的项目名称是什么？ **AI SaaSr-saas**
   - 您的代码位于哪个目录？ **./src**

## 🔧 环境变量

在 Vercel 控制面板中配置您的环境变量。

### 必需变量

以下 5 个变量缺失时，**构建会直接失败**，并在日志最前面打印出缺失清单
（校验逻辑见 `src/env.ts`）：

```bash
# 数据库
DATABASE_URL=postgresql://username:password@host:5432/database

# 会话签名密钥（至少 32 个字符）
# 生成方式：openssl rand -base64 32
BETTER_AUTH_SECRET=your-production-secret-key-min-32-chars

# Stripe 支付
STRIPE_SECRET_KEY=sk_live_your_stripe_secret_key
STRIPE_WEBHOOK_SECRET=whsec_your_webhook_secret
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_your_publishable_key
```

> `BETTER_AUTH_SECRET` 没有默认值，也不会回退到任何示例密钥。
> 缺失时 better-auth 会拒绝初始化，会话功能不可用。

### 强烈建议配置

这些变量有默认值，不填不会导致构建失败，但生产环境不填会出问题：

```bash
# 应用真实地址：不填则支付跳转、OAuth 回调都会指向 localhost
NEXT_PUBLIC_SITE_URL=https://your-domain.vercel.app

# 认证回调地址：绑定自定义域名后需要与站点地址保持一致
BETTER_AUTH_URL=https://your-domain.vercel.app
```

### 可选变量（用于完整功能）

```bash
# AI 服务（至少配置一个，否则 AI 功能不可用）
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_GENERATIVE_AI_API_KEY=...
XAI_API_KEY=...

# Redis（缓存与限流）
UPSTASH_REDIS_REST_URL=https://...
UPSTASH_REDIS_REST_TOKEN=...

# 邮件（邮箱验证与重置密码）
RESEND_API_KEY=re_...

# OAuth 提供商
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
GITHUB_CLIENT_ID=...
GITHUB_CLIENT_SECRET=...

# 管理员账号（逗号分隔）
ADMIN_EMAILS=admin@yourdomain.com

# 监控
SENTRY_DSN=https://...
```

> 变量名称必须与 `src/env.ts` 中的定义完全一致，填写未定义的变量不会生效。
> 完整清单见 [配置文档](../development/configuration)。

### 预览环境不共享生产密钥

预览（Preview）部署如果不想复用生产密钥，可以在预览环境中单独设置
`SKIP_ENV_VALIDATION=true` 跳过构建期校验。注意这只是跳过**构建期**校验，
预览环境运行时的功能仍需要对应的密钥才能正常工作。

### 设置环境变量

1. **通过 Vercel 控制面板：**
   - 转到项目设置
   - 导航到"环境变量"
   - 添加每个变量并选择适当的环境（生产、预览、开发）
   - 密钥类变量建议勾选 **Sensitive**

2. **通过 Vercel CLI：**
   ```bash
   vercel env add DATABASE_URL
   vercel env add BETTER_AUTH_SECRET
   vercel env add STRIPE_SECRET_KEY
   ```

## 🗄️ 数据库设置

### PostgreSQL 数据库

为您的生产数据库选择以下选项之一：

#### 选项 1：外部 PostgreSQL（推荐）

流行的 PostgreSQL 托管选项：
- **Neon** - [neon.tech](https://neon.tech/)（推荐）
- **Supabase** - [supabase.com](https://supabase.com/)
- **PlanetScale** - [planetscale.com](https://planetscale.com/)

登录Neon，创建一个新项目，在项目面板中点击"Connect",复制数据库URL，将数据库URL添加到 .env 文件的`DATABASE_URL`变量中。


#### 选项 2：Vercel Postgres

1. **向项目添加 Vercel Postgres：**
   ```bash
   vercel postgres create
   ```

2. **链接到您的项目：**
   ```bash
   vercel postgres connect
   ```

3. **获取连接详细信息：**
   - `DATABASE_URL` 将自动添加到您的环境变量中


### 数据库迁移

设置数据库后，运行迁移：

```bash
# 生成迁移文件
pnpm db:generate

# 将迁移应用到生产数据库
pnpm db:migrate
```

## 🔄 自动部署

### GitHub 集成

1. **连接您的 GitHub 仓库：**
   - 转到 Vercel 控制面板
   - 点击"导入项目"
   - 选择您的 GitHub 仓库
   - 配置构建设置

2. **自动部署触发器：**
   - ✅ **推送到主分支** - 部署到生产环境
   - ✅ **拉取请求** - 创建预览部署
   - ✅ **分支部署** - 部署特定分支

### 构建配置

Vercel 自动检测 Next.js 项目。默认配置：

```json
{
  "buildCommand": "pnpm build",
  "devCommand": "pnpm dev",
  "installCommand": "pnpm install",
  "outputDirectory": ".next"
}
```

### 自定义构建设置

在项目根目录创建 `vercel.json` 进行自定义配置：

```json
{
  "framework": "nextjs",
  "buildCommand": "pnpm build",
  "devCommand": "pnpm dev",
  "installCommand": "pnpm install",
  "functions": {
    "app/api/**/*.ts": {
      "maxDuration": 30
    }
  },
  "crons": [
    {
      "path": "/api/cron/cleanup",
      "schedule": "0 2 * * *"
    }
  ]
}
```

## 🌐 自定义域名

### 添加自定义域名

1. **在 Vercel 控制面板中：**
   - 转到项目设置
   - 导航到"域名"
   - 添加您的自定义域名

2. **DNS 配置：**
   - 添加指向 `cname.vercel-dns.com` 的 CNAME 记录
   - 或添加指向 Vercel IP 地址的 A 记录

3. **SSL 证书：**
   - Vercel 自动提供 SSL 证书
   - 默认启用 HTTPS

### 域名配置示例

```bash
# DNS 记录
CNAME   www     cname.vercel-dns.com
CNAME   @       cname.vercel-dns.com

# 或 A 记录
A       @       76.76.19.61
A       @       76.76.19.62
```

### 环境特定设置

```bash
# 生产环境变量
NODE_ENV=production
NEXT_PUBLIC_APP_URL=https://yourdomain.com

# 安全头（由 Vercel 自动处理）
# - X-Frame-Options
# - X-Content-Type-Options
# - X-XSS-Protection
# - Strict-Transport-Security
```

对于 Stripe webhooks，在您的 Stripe 控制面板中配置端点：

```
Webhook URL: https://yourdomain.com/api/webhooks/stripe
Events: customer.subscription.created, customer.subscription.updated, invoice.payment_succeeded
```

## 🚨 故障排除

### 常见问题

#### 构建失败

**问题：** 构建因依赖错误而失败
```bash
# 解决方案：清除缓存并重新安装
vercel --force
```

#### 环境变量未加载

**问题：** 环境变量在生产中未定义
```bash
# 检查环境变量
vercel env ls

# 本地拉取环境变量
vercel env pull .env.local
```

#### 数据库连接问题

**问题：** 无法连接到数据库
```bash
# 验证 DATABASE_URL 格式
postgresql://username:password@host:5432/database

# 本地测试连接
psql $DATABASE_URL
```

#### 函数超时

**问题：** API 路由在 10 秒后超时
```json
// vercel.json
{
  "functions": {
    "app/api/**/*.ts": {
      "maxDuration": 30
    }
  }
}
```

### 性能优化

#### Edge Runtime

使用 Edge Runtime 获得更快的响应时间：

```typescript
// app/api/example/route.ts
export const runtime = 'edge'

export async function GET() {
  return Response.json({ message: 'Hello from Edge Runtime!' })
}
```

#### 静态生成

优化静态页面以获得更好的性能：

```typescript
// app/page.tsx
export const revalidate = 3600 // 每小时重新验证

export default function HomePage() {
  return <div>您的内容</div>
}
```
